# MediTrack Requirements Validation Checklist

**Version:** 0.1  
**Purpose:** Check the MediTrack SRS for clarity, testability, consistency, completeness, and clinic-specific risks.

**Answer rule:** Yes is always the good answer. Use Yes, No, or N/A. For every No, record the requirement ID and a short reason in the run sheet.

| ID | Item | Answer | Evidence | Where question came from |
|---|---|---|---|---|
| CL-001 | Does each requirement describe only one system obligation? |  |  | Rule: Atomic |
| CL-002 | Does every requirement avoid undefined vague words? |  |  | Rule: Clear |
| CL-003 | Does every response-time requirement include a measurable number and unit? |  |  | Rule: Testable |
| CL-004 | Can a pass/fail test be written for every requirement? |  |  | Rule: Testable |
| CL-005 | Do the requirements define one consistent appointment duration? |  |  | Risk: Conflicting appointment lengths |
| CL-006 | Does the SRS explain how simultaneous booking attempts are prevented from creating double bookings? |  |  | Risk: Double bookings |
| CL-007 | Does the SRS define what confirmation a patient receives after booking? |  |  | User: Patient |
| CL-008 | Does the SRS specify when appointment reminders are sent? |  |  | Risk: Forgotten appointments |
| CL-009 | Does the SRS identify which user roles may view patient medical records? |  |  | User: Patient; Risk: Privacy |
| CL-010 | Does the SRS specify measurable controls for protecting stored patient records? |  |  | User: Data protection officer; Risk: Privacy |
| CL-011 | Does the SRS state measurable accessibility needs for elderly patients? |  |  | User: Patient; Risk: Elderly patients excluded |
| CL-012 | Does the SRS define how emergency walk-in patients are handled? |  |  | Risk: Emergency walk-ins excluded |
| CL-013 | Does the SRS allow receptionists to book walk-in appointments? |  |  | User: Receptionist |
| CL-014 | Does the SRS allow doctors to view their daily appointment schedule? |  |  | User: Doctor |
| CL-015 | Does the SRS define the clinic administrator’s system responsibilities? |  |  | User: Clinic administrator |
| CL-016 | Does the SRS define the data protection officer’s responsibilities? |  |  | User: Data protection officer |
| CL-017 | Does the SRS define what makes an appointment active? |  |  | Rule: Unambiguous; Risk: Appointment-limit confusion |
| CL-018 | Does the SRS define the clinic policy used to handle overdue payments? |  |  | Rule: Complete; Risk: Payment disputes |
| CL-019 | Does the SRS specify the expected system capacity for busy Monday mornings? |  |  | Risk: Peak-time delays |
